ONGOING PROJECT / 2026

Mneme
Memory
MCP

Mneme Memory MCP gives AI agents a shared long-term memory layer. It helps them carry useful knowledge between conversations without turning memory into an opaque pile of notes.

The work focuses on retrieval, provenance, correction, scope, and forgetting. People should be able to see why a memory appeared, fix it when it is wrong, and remove it when it no longer belongs.

BUILT WITH
Model Context Protocol, Python, PostgreSQL, local models
