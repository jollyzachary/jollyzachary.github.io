# Zachary Jolly / Personal Portfolio

A small personal site about Zachary Jolly and selected things he has built.
Company products and company-owned visual assets are intentionally kept separate.

The route-based site is built with Svelte 5, SvelteKit, TypeScript, and
handcrafted CSS. It is prerendered as a static site for GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

The local site runs at `http://127.0.0.1:3000/`.

## Production build

```bash
npm run build
```

The static output is written to `build/`.
